Banfico Banking API

Spring Boot · Keycloak JWT · PostgreSQL  |  Base URL: http://localhost:8080

Roles

admin

  • Full access to everything
  • Create / delete managers
  • Delete accounts and customers

BankManager

  • Register new customers
  • Open (create) accounts
  • View all customers, accounts, transactions, payments

user (customer)

  • Own accounts & transactions only
  • Add / manage own beneficiaries
  • Make transfers (payments)
  • View own payments
  • Edit own profile

Public

  • GET /api/v1/health
  • GET /api/v1/info

Fund Transfer

Only customers (USER role) can transfer. The preview step lets you confirm details before paying. The POST is idempotent — resending the same paymentId UUID never double-charges.

MethodURLAccessDescription
GET /api/v2/transfer/preview?fromAccountId=&recipientAccountNo=&amount= User Preview: returns from account, to account holder name, amount, estimated time — show to customer before they confirm
POST /api/v2/transfer User Execute transfer. Client provides a paymentId UUID. If already COMPLETED → returns cached result. If PENDING → 409.

Payment confirmation flow

1. GET /api/v2/transfer/preview?fromAccountId=<id>&recipientAccountNo=ACC-001&amount=500
   → { fromAccountNo, fromAccountBalance, toAccountNo, toAccountName, amount, estimatedAt }

2. Show customer: "Send £500 from ACC-XXXX to John Doe (ACC-001) at 14:32?"

3. POST /api/v2/transfer  { paymentId: <new-uuid>, fromAccountId, recipientAccountNo, amount, note }
   → PaymentResponse with status COMPLETED / FAILED

Payment History

All list endpoints support pagination: ?page=0&size=20&sort=initiatedAt,desc. The response header X-Total-Count carries the total number of records.

MethodURLAccessDescription
GET/api/v1/paymentsAdminBankManagerUserStaff → all (optional ?accountId=); User → own. Paginated.
GET/api/v1/payments/{paymentId}AuthenticatedGet single payment by ID

Transactions

Returns all debit/credit entries for an account. Supports pagination: ?page=0&size=20. Default sort: newest first. X-Total-Count in response headers.

MethodURLAccessDescription
GET/api/v1/transactions?accountId=AdminBankManagerUserStaff → any account; User → own accounts only. Paginated.

Pagination

Request params

  • page — zero-based page number (default 0)
  • size — items per page (default 20)
  • sort — field,direction e.g. transactionTime,desc

Response

  • Body: { content: [...], totalElements, totalPages, number, size }
  • Header: X-Total-Count: 150

Paginated endpoints
